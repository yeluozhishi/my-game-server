### skill

    需要Scene，成为其成员
    成员：config, finite state machine, source, target

### 过程
    非弹道技能
    1. 玩家使用技能开始时，检查玩家状态，技能cd等。
    2. 获取目标位置，检查释放位置，根据技能配置获取对应的目标。比如单个目标、多个目标、范围内目标。
    3. 获取技能配置，获取对应的技能伤害脚本，先计算伤害值，再获取扣血脚本计算扣血量，最终扣除血量。
    4. 根据配置，是否释放后续buff等。
    5. 后续技能释放事件、消息发送

    伤害计算：玩家双方的攻防数值（含加成）相减后，在计算各种模块的加成或衰减，得到最终技能伤害值。



### buff
    生成buff对象，添加到地图的buff列表中或者是玩家对象身上，通过定时器刷新buff状态。
